这是一个给"知道自己该做什么、但需要一点外力推一把"的人用的工具。

和传统待办清单不同，它不让你自由拖拽、不让你建项目分类、不让你设优先级标签。它只做一件事：你把每天固定的时间块填进去，每天勾选完成，不勾就记一笔拖欠——拖欠数字永不自动清零，像一面墙上的划痕，越积越多，直到你把它补回来。

核心设计决策：

卡片极简，最短时间完成打卡操作，不花时间在任务前期准备，客片设置只侧重任务性质和完全与否，时间不固定，具体分配自由灵活

拖欠次数不清零——不是惩罚，是负向激励。你今天没打卡，明天这个数字还在那儿看着你
时间块优先——先排时间再填任务，帮你建立"这个时间段就是干这件事"的身体记忆
一键休假——不是让你愧疚地关掉页面，而是正式地"请个假"，到期自动恢复
双模式存储——不想登录就直接用（数据留本地），换设备频繁就 GitHub 一键登录（数据同步云端）
适合谁： 在校学生、考研党、自由职业者、任何有固定每日作息但缺乏外部监督的人。

不适合谁： 任务每天变来变去的人（用 Todoist）、需要团队协作的人（用 Notion）、想要统计报表的人（用 Toggl）。
